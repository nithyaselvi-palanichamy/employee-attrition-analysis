# Prediction of Employee Attrition Using Machine Learning

## Project Overview

Employee attrition is one of the major challenges faced by organizations and HR departments. During my experience in the HR department, I observed that sudden employee attrition can negatively impact organizational productivity, employee retention, and business continuity.

To address this challenge, I conducted an employee attrition analysis using data collected from **188 employees** through a **Google Forms questionnaire**. The objective of this project was to identify the major factors influencing employees' intention to leave and use machine learning algorithms to predict employee attrition.

After the machine learning analysis, I developed an interactive **Power BI dashboard** to present the findings and insights in a simple and easy-to-understand format.

---

##  Project Objective

The main objectives of this project were to:

* Analyze employee-related data to understand the factors influencing attrition.
* Identify the major factors that may influence employees' decisions to leave an organization.
* Apply machine learning algorithms to predict employee attrition.
* Compare the performance of different machine learning models.
* Develop an interactive Power BI dashboard to visualize attrition patterns and key insights.
* Provide data-driven insights that can help HR teams take preventive retention actions.

---

##  Data Collection

The data was collected from **188 employees** using a structured questionnaire created with **Google Forms**.

The collected data was analyzed to understand employee-related factors and their relationship with attrition and employees' intention to leave.

## Machine Learning Models

Three machine learning algorithms were applied using **IBM SPSS Modeler**:

1. **Decision Tree**
2. **Random Forest**
3. **Artificial Neural Network (ANN)**

The models were compared based on their prediction performance to identify the best-performing algorithm.

---

##  Model Performance

Among the three machine learning algorithms, the **Artificial Neural Network (ANN)** achieved the highest accuracy.

| Machine Learning Model          | Performance         |
| ------------------------------- | ------------------- |
| Decision Tree                   | Good interpretation |
| Random Forest                   | 61.5%               |
| Artificial Neural Network (ANN) | **69.1% Accuracy**  |

###  Best Performing Model

**Artificial Neural Network (ANN)** achieved an accuracy of **69.1%**, outperforming the Decision Tree and Random Forest models used in this project.
